# Mock-ups

These two images were generated by Gemini 4 Argon (through Antigravity's `generate_image` tool) from a written design brief, before any UI code was written.
They fix the visual direction: civic signage, pale concrete background, harbour navy text, and each destination as a solid slab in its cart colour.

- `phone-answer.jpg`: the phone answer screen for "Pizza box".
- `desktop-overview.jpg`: the desktop layout with search on the left and the browsable rule list on the right.

Warning: the text inside the images is illustrative and is not an official rule.
The quote shown in `desktop-overview.jpg` ("Empty and rinse glass bottles and jars ... Keep lids separate") was invented by the image model.
It contradicts the City's published tip for plastic bottles ("Lids On!") and appears nowhere in the City's guidelines.
The real app only ever shows quotes that are verified against the saved City pages in `data/snapshots/`.

The image model's own description of the layout, palette and type is in `GENERATOR_NOTES.md`.
